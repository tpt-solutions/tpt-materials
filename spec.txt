## 1. Open Source Declaration

`tpt-materials` is a fully open-source, MIT-licensed computational engine for **micro-scale material physics**: crystal plasticity, phase-field modeling, diffusion, micro-mechanics, and degradation. Every crate, every constitutive model, and every solver is freely available under MIT OR Apache-2.0.

### Why Fully Open Source for Materials?

The materials simulation space is trapped between academic code and commercial black boxes:

1. **The GPL Academic Trap:** The most powerful micro-mechanics tools are GPL/LGPL-licensed academic code (DAMASK, MOOSE, FEniCS, LAMMPS). This makes them legally toxic for commercial R&D teams at steel mills, battery manufacturers, and aerospace suppliers.
2. **The Commercial Black Box:** Commercial alternatives (Abaqus UMAT ecosystems, ANSYS Material Designer, Thermo-Calc) cost $50k-$300k per seat and hide their constitutive models behind compiled binaries.
3. **The Scale Disconnect:** Device engineers (batteries, turbines, implants) need macro-scale material properties, but those properties emerge from micro-scale physics. Currently there is no clean bridge between the two.

`tpt-materials` is that bridge. It provides pure-Rust, MIT-licensed micro-mechanics solvers that generate the **degradation curves, fatigue limits, and effective properties** consumed by your other TPT repositories (`tpt-energy`, `tpt-transport`, `tpt-electronics`, `tpt-medical`). Because it compiles to WebAssembly, materials scientists can run RVE homogenization and phase-field simulations directly in the browser.

```rust
pub enum CrystalStructure {
    FCC { a: f64 },
    BCC { a: f64 },
    HCP { a: f64, c: f64 },
    Diamond { a: f64 },
    SimpleCubic { a: f64 },
    BCT { a: f64, c: f64 },
    Custom { lattice_parameters: LatticeParameters, space_group: u32 },
}

pub struct LatticeParameters {
    pub a: f64,
    pub b: f64,
    pub c: f64,
    pub alpha: f64,
    pub beta: f64,
    pub gamma: f64,
}

pub struct MillerIndex {
    pub h: i32,
    pub k: i32,
    pub l: i32,
}

pub struct SlipSystem {
    pub slip_direction: Vector3,       // Burgers vector direction (s)
    pub slip_plane_normal: Vector3,    // Plane normal (n)
    pub critical_resolved_shear_stress: f64,
}

impl CrystalStructure {
    pub fn slip_systems(&self) -> Vec<SlipSystem> {
        match self {
            CrystalStructure::FCC { .. } => {
                // 12 slip systems: {111}<110>
                self.fcc_slip_systems()
            }
            CrystalStructure::BCC { .. } => {
                // 12 slip systems: {110}<111>
                self.bcc_slip_systems()
            }
            CrystalStructure::HCP { .. } => {
                // Basal, prismatic, pyramidal systems
                self.hcp_slip_systems()
            }
            _ => vec![],
        }
    }
}

impl SlipSystem {
    pub fn schmid_tensor(&self) -> Matrix3 {
        // M = sym(s ⊗ n) = 0.5 * (s⊗n + n⊗s)
        let s = self.slip_direction;
        let n = self.slip_plane_normal;
        0.5 * (outer(s, n) + outer(n, s))
    }
    
    pub fn resolved_shear_stress(&self, stress: &Matrix3) -> f64 {
        // τ = σ : M (double contraction)
        let m = self.schmid_tensor();
        (stress * m).trace()
    }
}
```

#### `tpt-mat-crystal-plasticity`

```rust
pub struct CrystalPlasticityModel {
    pub crystal_structure: CrystalStructure,
    pub slip_systems: Vec<SlipSystem>,
    pub hardening_law: HardeningLaw,
    pub rate_sensitivity: f64,         // m (viscoplastic exponent)
    pub reference_strain_rate: f64,    // γ̇0
    pub elastic_tensor: ElasticTensor,
}

pub enum HardeningLaw {
    Voce {
        tau_0: f64,       // Initial slip resistance
        tau_sat: f64,     // Saturation slip resistance
        h_0: f64,         // Initial hardening rate
    },
    PowerLaw {
        k: f64,
        n: f64,
    },
    KocksMecking {
        theta_0: f64,     // Stage II hardening rate
        g_0: f64,
    },
    Combined {
        // Voce + latent hardening matrix
        latent_hardening: Vec<Vec<f64>>,  // q_ab matrix
    },
}

impl CrystalPlasticityModel {
    pub fn plastic_velocity_gradient(
        &self,
        stress: &Matrix3,
        dt: f64,
    ) -> PlasticIncrement {
        // Calculate slip rates on all systems
        // Lp = Σ γ̇α * (sα ⊗ nα)
        
        let mut lp = Matrix3::zeros();
        let mut slip_rates = Vec::with_capacity(self.slip_systems.len());
        
        for system in &self.slip_systems {
            let tau = system.resolved_shear_stress(stress);
            let gamma = system.critical_resolved_shear_stress;
            
            // Viscoplastic power law flow rule:
            // γ̇α = γ̇0 * |τα/γα|^(1/m) * sign(τα)
            let ratio = (tau / gamma).abs();
            let rate = self.reference_strain_rate 
                * ratio.powf(1.0 / self.rate_sensitivity)
                * tau.signum();
            
            slip_rates.push(rate);
            lp += rate * outer(system.slip_direction, system.slip_plane_normal);
        }
        
        PlasticIncrement {
            velocity_gradient: lp,
            slip_rates,
        }
    }
    
    pub fn update_hardening(
        &mut self,
        slip_increment: &[f64],
    ) {
        // Update slip resistance based on hardening law
        // γα += Σ h_ab * |Δγb|  (Voce saturation)
    }
}

pub struct PlasticIncrement {
    pub velocity_gradient: Matrix3,
    pub slip_rates: Vec<f64>,
}

pub struct CpFemSolver {
```

```rust
pub enum PhaseFieldModel {
    AllenCahn {
        // Non-conserved order parameter (grain growth, ordering)
        free_energy: FreeEnergyFunctional,
    },
    CahnHilliard {
        // Conserved order parameter (spinodal decomposition)
        free_energy: FreeEnergyFunctional,
    },
    Kobayashi {
        // Solidification with temperature coupling
        latent_heat: f64,
    },
    MultiPhase {
        // Multiple order parameters for multi-grain systems
        num_grains: u32,
    },
}

pub struct FreeEnergyFunctional {
    pub bulk: BulkEnergy,
    pub gradient_coefficient: f64,
}

pub enum BulkEnergy {
    DoubleWell { barrier_height: f64 },
    Polynomial { coefficients: Vec<f64> },
    RegularSolution { interaction_parameter: f64 },
}

impl PhaseFieldSolver {
    pub fn step_allen_cahn(&mut self) {
        // Allen-Cahn equation:
        // ∂η/∂t = -L * δF/δη = -L * (df/dη - κ∇²η)
        //
        // Discretized:
        // η^(n+1) = η^n - dt * L * (df/dη - κ * laplacian(η))
        
        let laplacian = self.compute_laplacian(&self.order_parameter);
        let df_deta = self.compute_bulk_derivative(&self.order_parameter);
        
        for i in 0..self.order_parameter.len() {
            self.order_parameter[i] -= self.time_step * self.mobility 
                * (df_deta[i] - self.gradient_coefficient * laplacian[i]);
        }
    }
    
    pub fn step_cahn_hilliard(&mut self) {
        // Cahn-Hilliard equation:
        // ∂c/∂t = ∇·(M∇(δF/δc))
        //
        // Split into two equations:
        // μ = df/dc - κ∇²c  (chemical potential)
        // ∂c/∂t = ∇·(M∇μ)
```

```rust
pub enum HomogenizationMethod {
    Voigt,           // Iso-strain (upper bound)
    Reuss,           // Iso-stress (lower bound)
    Hill,            // Average of Voigt and Reuss
    MoriTanaka,      // Eshelby inclusion-based
    SelfConsistent,  // Iterative self-consistent scheme
    FftBased,        // FFT-based spectral method (Moulinec-Suquet)
    FemBased,        // Full-field FEM RVE
}

pub struct Homogenizer {
    pub method: HomogenizationMethod,
}

impl Homogenizer {
    pub fn effective_stiffness(
        &self,
        phases: &[Phase],
        volume_fractions: &[f64],
    ) -> ElasticTensor {
        match self.method {
            HomogenizationMethod::Voigt => self.voigt_average(phases, volume_fractions),
```

```rust
        k: f64,       // Rate constant
    },

        ms: f64,      // Martensite start temperature
        mf: f64,      // Martensite finish temperature
        alpha: f64,   // Rate parameter
    },
}

impl PhaseTransformation {
    pub fn transformed_fraction(
        &self,
        temperature: f64,
        time: f64,
    ) -> f64 {
        match &self.kinetics {
            TransformationKinetics::JohnsonMehlAvrami { n, k } => {
                // f = 1 - exp(-k * t^n)
                1.0 - (-k * time.powf(*n)).exp()
            }
            TransformationKinetics::KoistinenMarburger { ms, alpha, .. } => {
                // f_m = 1 - exp(-α * (Ms - T)) for T < Ms
                if temperature < *ms {
                    1.0 - (-alpha * (ms - temperature)).exp()
                } else {
                    0.0
                }
            }
        }
    }
}
```

## 14. Summary

`tpt-materials` is a fully open-source, MIT-licensed, pure-Rust computational engine for micro-scale material physics:

- **Crystallography** — Crystal structures, slip systems, Miller indices
- **Crystal Plasticity** — CP-FEM, hardening laws, texture analysis
- **Phase-Field** — Allen-Cahn, Cahn-Hilliard, grain growth, solidification
- **Micro-Mechanics** — RVE generation, homogenization, composite micro-mechanics
- **Diffusion & Transformation** — Fick's laws, JMAK kinetics, CALPHAD
- **Degradation** — GTN damage, microstructural fatigue, corrosion
- **Energy Materials** — Battery electrode degradation, hydrogen storage
- **Manufacturing** — Additive manufacturing, welding, heat treatment
- **Informatics** — Property databases, ML surrogate models

All crates maintain the strict MIT chain, leverage the TPT substrates (`tpt-math`, `tpt-engineering`, `tpt-science`, `tpt-fem`), and compile to WebAssembly for browser-based microstructure simulation.

No proprietary cores. No GPL traps. No academic lock-in. Just open source.
